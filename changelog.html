v1.1.0
Agust 17, 2026

Matchmaking Update

NEW FEATURES

  • Masteries, the player page now has a mastery tab showing some extra information about each hero they play showing some less meta information.
  • Added basic prediction screen showing the top matches live and predicting the outcome. This will be used to tune the prediction algorithm and improve PR ratings.
  • Added a warning to show matches that take place after the matchmaking update.
  • Added RP bars on the player page showing current rank in rp and progress towards the next rank.
  • Added gamemode detection for match history | street brawl will not count for PR calculations.

ADJUSTMENTS

  • Adjusted PR calculations minorly to try to fix over inflation.
  • Sped up some background processes with syncing accounts.

BUG FIXES

  • Fixed scroll bars appearing unnecessarily.
  • Fixed objective damage counting when it should not for unindexed matches.
  • Fixed leaderboard display issues.
  • Fixed several minor bugs.

Database Updates and Bug Fixes

NEW FEATURES

  • Added a deep scan feature to scan and log all possible matches for an account.

  • Fixed search bars not allowing autofill on other pages.
  • Fixed rank badges not displaying correctly.
  • Fixed unindexed matches hurting PR calculation.
  • Fixed rare bug where names were displayed as ids in match page.
  • Fixed issue with trending players's ranks not displaying.
